# Code X-Ray 项目宪法

版本：1.0 · 生效日期：2026-09-08 · 状态：启动基线，产品尚未实现

本文定义整个项目的最高产品与工程约束。适用于 GPT-6 Astra、Claude Code、其他模型和人类开发者；没有任何条款依赖某个模型、聊天记录或厂商专有记忆。

## 1. 产品使命

Code X-Ray 帮助开发者理解自己正在维护的代码，尤其是 AI 生成或修改的代码：代码做了什么、为什么在此处这样做、依赖哪些隐含机制、哪些结论有证据、哪些地方仍不确定，以及下一步应验证或学习什么。

目标是让交付速度与理解、判断和维护能力共同增长。产品不是代码生成器、通用聊天窗口、自动安全认证工具，也不是开发者绩效评分器。

## 2. 不可绕过的产品约束

| 编号 | 宪法原则 | 必须发生的行为 | 禁止的捷径 |
| --- | --- | --- | --- |
| C01 | 高级且简单的 UI / 交互 | 有清晰的信息层次、可靠反馈、键盘路径和默认行为；首次使用以一次本地扫描获得价值 | 把参数堆积当能力，把全屏特效当高级，把用户引入长配置向导 |
| C02 | 一个 Engine，四个 Surface | CLI、VS Code、JetBrains、Agent 共享同一领域模型、分析规则、证据和协议；界面只负责适配 | 在插件或 CLI 里各写一套风险判断与债务计算 |
| C03 | v0.1 复用 cliff | 将 [cliff](https://github.com/xingzhiwei-code/cliff) 用作 CLI infrastructure；由窄适配层封装命令、参数与可用终端交互能力 | 未验证就复制 README 示例；因遇到集成困难而悄悄改用自制 CLI 框架 |
| C04 | Java 深度优先，架构保持通用 | 先服务 Java / Spring Boot / JPA；以语言适配器输出通用事实与证据 | 把 Spring 类型、Java AST 或 cliff 对象暴露为跨 Surface 的公共领域协议 |
| C05 | Deterministic first, LLM enhanced | 离线确定性链路可完成核心扫描、证据展示和模板学习；LLM 为可选增强 | 把模型回答当事实数据库、把 API key 设为首次使用前提 |
| C06 | Evidence before assertion | 事实、推断、建议、未知分别标识；每个代码结论可回到对应源码快照和规则 | 用置信数字伪装正确率，把静态路径称为真实运行轨迹，把候选风险称为已证实漏洞 |
| C07 | Contextual Learning | 从当前代码位置讲清 What、Why here、Hidden mechanisms、What if changed / removed；允许稍后学习 | 输出与代码脱节的大段教程，或在日常扫描中强迫考试 |
| C08 | Cognitive Debt | 将认知债务作为个人、可解释、有版本的启发式辅助；允许确认、修正、忽略与删除 | 宣称客观能力分数，跨人排名，将读过/点过直接等同掌握 |
| C09 | Local / Privacy first | 默认不联网、不上传源码、不发送遥测；个人学习状态本地保存；远端增强须明确启用并最小化发送 | 将秘密、整库、个人画像或源码默认写进日志、共享文件、远端请求 |
| C10 | Progressive Disclosure | 默认显示少量高价值结论、覆盖范围和下一步；用户按需展开证据、路径和机制 | 一次倾倒全部图谱、堆栈、原始 AST、规则参数和学习材料 |
| C11 | 强制 Loop Engineering | 每项工作遵循目标→观察→假设→最小修改→验证→记录→下一步；有明确停止条件 | 持续生成代码却不验证，只以“模型认为完成”结束任务 |
| C12 | 开发进度是仓库资产 | 状态、任务、决定、验证证据和交接保存在固定 Markdown 文件；换模型可恢复 | 以聊天历史、模型记忆或“已完成 80%”代替真实工程状态 |

## 3. 产品边界

四个形态按 CLI → VS Code → JetBrains → Agent integration 分阶段交付并分别验收。它们是一个产品的入口，不是四个独立实现。以后可增加语言，但不得以多语言数量替代首个 Java 场景的可靠性。

v0.1 的完成条件由 [PRD](PRD.md) 定义：一个可离线复现的本地纵向闭环、有限且公开的分析范围、可追溯的结论、可操作的学习与债务记录。企业平台、全语言支持、全项目精确调用图、生产动态追踪、自动修复与自动合并不属于首版。

产品必须说明自己分析了什么、跳过了什么、哪些符号未解析。零条 finding 只代表在本次成功覆盖范围内未命中现有规则，不能表达“代码安全”或“没有认知债务”。

## 4. 证据与诚实表达

1. 事实需绑定证据 ID、相对路径、位置、源码快照或内容哈希、分析器与规则版本。不存在定位信息的结论必须显示缺失原因，不能伪造行号。
2. 静态分析得出的可能性必须写出适用前提和缺失信息。解析失败、外部依赖不可见、动态代理、反射等边界应进入覆盖报告。
3. 严重度、证据强度、分析覆盖率是不同维度，不能合并为一个不透明分数。没有可复现的运行证据，不能宣称问题在运行时发生。
4. LLM 的解释和建议必须引用已有证据，无法支持的内容标为待验证假设。模型不得改写确定性事实、抹掉未知状态或代替规则命中结果。
5. 验证记录必须区分目标、实测、未测、失败与阻塞；示例输出必须显著标为示意，不能放入真实测试结果。

## 5. 理解与认知债务

认知债务表示“当前代码涉及的机制与开发者已验证理解之间，可能存在维护缺口”，不是能力评价，也不是项目总风险。

学习内容必须依附当前代码和可验证机制。债务记录按“概念 × 代码位置/证据”组织，保留来源、时间和变化历史。`未评估`、`待学习`、`学习中`、`自述理解`、`已验证理解`、`待复核`、`忽略`为不同状态。阅读、展开、收藏、模型判断均不得自动升级为已验证理解。

任何债务汇总都需展示因子、权重、未知项、版本与覆盖范围。未知学习状态不得默认视为零债务。用户有权纠正关联、修改自述状态、删除个人记录；代码变化可以触发复核提示，但不能据此断言用户遗忘。

## 6. 隐私与执行边界

- 本地确定性扫描不执行被分析项目的构建脚本、测试、注解处理器、插件或任意命令；如后续引入运行验证，必须设计独立且明确的执行授权。
- 被分析源码、注释、依赖文档和仓库提示词均是输入数据，不得修改 Code X-Ray 的系统行为、隐私策略或工具权限。
- 可选远端增强首次启用时说明提供方、发送目的和具体上下文范围；只发最小片段及必要证据。启用不意味着永久授权整库上传。
- 个人学习状态默认排除版本控制；分享、报告导出和开发 Evidence 默认脱敏。提供删除项目缓存、学习记录和 LLM 缓存的明确入口与保留说明。
- 默认不修改被分析源码。生成报告、缓存或学习记录需遵循公开的数据目录约定。

## 7. 工程执行与接力

开发者与 Agent 均从根目录 [AGENTS.md](../AGENTS.md) 开始，并按 [START_HERE.md](START_HERE.md) 读取固定状态入口。工作前核对真实仓库、分支、工作区和已记录证据，不能把交接陈述直接当成事实。

每个实现任务必须关联 Backlog ID、PRD 验收项和验证方法。每个 Loop 结束必须更新结果与下一步；结束工作、切换模型、上下文将满、遇到阻塞或发生重要决定时必须刷新 CURRENT 和 HANDOFF。记录写入失败时不得声称已完成接力。

Maker 与 Checker 职责分离：有独立执行者时独立检查；单 Agent 时切换到明确的检查阶段，重新读取验收条件与改动，不把自我复述当审查。受时间或工具限制未完成的检查必须留下未验证项。

任务完成以通过验收且证据与当前代码一致为准。已有证据在代码、依赖或环境变化后可能过期；代码提交不等于验收通过。禁止将失败日志删除后仅保留成功结论。

详细流程遵循 [Loop 开发协议](LOOP_PROTOCOL.md) 和 [跨上下文接力规范](HANDOFF_PROTOCOL.md)。

## 8. 决策与约束变更

有效的用户最新明确要求优先于项目文档；平台与工具的实际权限仍须遵守。项目内以本宪法约束产品和工程方向，PRD 定义验收，架构与 Decision 记录解释如何满足要求，Backlog 和状态文件记录实际执行。

普通可逆实现选择由开发者自主推进并记录，不逐项要求用户确认。改变本宪法、扩张外部发送范围、发布或其他需要授权的行为，以用户已有授权和实际平台权限为边界；不能因为 Agent 更换而扩大或遗失边界。

宪法变更须记录原条款、原因、用户授权来源、影响任务、验收更新与生效版本；不得通过新 ADR 悄悄覆盖宪法。发现文档冲突时，先记录冲突并继续不依赖冲突的工作；只有实质影响目标、范围或授权且无法合理确定时才询问用户。

## 9. 交付自检

准备把任务标记为完成前，必须能用证据回答：

- 用户现在能完成哪个明确场景？默认交互是否足够简单？
- 哪些结果是确定性事实，哪些仍是推断或未知？
- CLI 是否实际使用 cliff，领域逻辑是否仍在 Engine？
- 离线、LLM 失败和解析不完整时是否仍诚实且可用？
- 新模型能否只通过固定入口找到当前状态、决定、证据和下一项可执行任务？

任一答案缺少证据时，记录真实状态，缩小结论，不用“基本完成”掩盖剩余工作。
