# ADR-003：学习侧定位——不冻结，继续迭代

- 日期：2026-10-11
- 状态：已采纳

## 背景

链路摘要变成主循环后，profile / debt / learn 是否还有价值：一度考虑冻结学习侧（"每天聚焦链路，日积月累自然融会贯通"）。

## 决策

不冻结，继续迭代，但重排：

- 保留 concept 三态（to-learn / learning / verified）+ profile 画像。
- 冻结 debt-model-v2 复杂公式的新投入（非线性暴露因子等不再演进）。
- 学习是链路的副作用：在链路中当场认领概念、学掉，而不是先看仪表盘再去学。

## 理由

- 看过≠学会：三态仍是必要的"掌握"信号，否则"融会贯通"是自我欺骗。
- 链路覆盖有盲区：链路是任务的投影，天天写 CRUD 就碰不到并发/JVM/网络；概念地图负责"推"的查漏，与链路的"拉"不是替代关系。
- profile 在新使命下更重要："用人话讲"得先知道"你是谁"——前端背景才能拿前端概念打比方。

## 后果

- v0.6 M3 实现链路×学习联动最小版（conceptId 认领、verified 仍 CLI 显式、debt 加"链路出现 N 次"视角）。
- debt 公式冻结，只做呈现层小改。
