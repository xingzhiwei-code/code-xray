# ADR-005：v0.7 主题选择——链路打磨优先于 TypeScript

- 日期：2026-10-11
- 状态：已采纳

## 背景

v0.6 留下 R5/R6/R7 三个链路精度问题；冻结评估集缺后 3 条规则覆盖；多语言（TypeScript）是立项之本的必经之路，用户提议 personal-language-agent 可作 TS dogfood 候选。

## 决策

v0.7 主题定为"讲懂打磨"（R5/R6/R7 + 评估集补全）；TypeScript 推迟到 v0.8 候选。

## 理由

- 用户主战场是公司 Spring Boot 项目（Java），链路质量决定日常体验；公司项目两周 dogfood 正在进行，链路精度正是要验证的东西。
- v0.6 的 9 环链路自己还在打磨期，此时在 TS 上另起一套框架语义（Express/Koa 路由、Prisma/TypeORM 数据访问），大概率重复踩同一个坑。
- Analyzer 接口是否设计得当，需要实战检验后再上第二门语言，一次做对的概率更大。

## 后果

- v0.7 不做任何多语言工作；tree-sitter 选型留到 v0.8。
- v0.8 候选：TypeScript analyzer（`packages/analyzer-typescript`）+ personal-language-agent dogfood。
