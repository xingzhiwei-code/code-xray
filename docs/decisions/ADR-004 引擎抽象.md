# ADR-004：引擎抽象（Analyzer 接口）

- 日期：2026-10-11
- 状态：已采纳（v0.6 M1 执行）

## 背景

`packages/analyzer-java` 被 engine 直接依赖，写死 Java。立项之本要求多语言（Java/Node/Go/Python/Rust）为必经之路。

## 决策

- 新增 `packages/analyzer` 定义 `Analyzer` 接口（`parse(file) → CST`、统一 `query` 方法）。
- `packages/analyzer-java` 改为实现该接口；engine facade 改为依赖接口，不再直接 import analyzer-java。
- 接口设计兼容未来 tree-sitter 接入；**本迭代不引入 tree-sitter、不换 java-parser、零行为变化**。

## 理由

- 不切这层，以后每加一门语言都要动引擎；切完后加语言只需实现接口。
- tree-sitter 给几十种语言提供同一套 CST 接口，是未来的解析底座；但本迭代只做接口，行为零变化，用 evals 双保险。

## 后果

- M2 链路能力建在新接口上。
- 下一门语言（跟随用户的真实需求，如 TypeScript）只需新增 `packages/analyzer-<lang>` 实现。
